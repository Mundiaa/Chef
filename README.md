# Chef Melvin Mushabe Portfolio

A personal culinary portfolio website for Chef Melvin Mushabe, founder of MFAME Creations.

The site showcases Chef Melvin's story, services, food photography, recipe development work, interactive recipe examples, and contact details for bookings and collaborations.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- GSAP + Flip for gallery animations

## Project Structure

```text
Assets/        Images and videos
CSS/           Site styling
JS/            Interactivity and gallery animation
index.html     Main website page
